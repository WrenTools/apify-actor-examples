# Apify Actor examples

Small, runnable examples for the Apify Actors published by [Wrenkit](https://apify.com/wrenkit). Each folder
is one task, with a Python and a Node version and a README that explains the output, the price and the limits.

| Example | Actor |
|---|---|
| [Transcribe audio and video files to text and subtitles](transcribe-audio-to-text-and-subtitles/) | [Audio & Video Transcription](https://apify.com/wrenkit/audio-video-transcription) |
| [Turn PDFs into Markdown and RAG-ready chunks](pdf-to-markdown-and-rag-chunks/) | [PDF to Text & Markdown Extractor](https://apify.com/wrenkit/pdf-text-markdown-extractor) |
| [Merge lead lists from CSV, JSON and Excel files and remove duplicates](merge-and-dedup-lead-lists/) | [Merge & Dedup Datasets](https://apify.com/wrenkit/dataset-merge-dedup) |

**Disclosure:** we built and sell the Actors these examples call. The examples are written with AI assistance, and
each one is run against the live Actor before it is published here.

Issues and questions about an example are welcome in this repository's Issues.
