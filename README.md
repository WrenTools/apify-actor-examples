# Apify Actor examples

Small, runnable examples for the Apify Actors published by [WrenTools](https://apify.com/wrentools). Each folder
is one task, with a Python and a Node version and a README that explains the output, the price and the limits.

| Example | Actor |
|---|---|
| [Transcribe audio and video files to text and subtitles](transcribe-audio-to-text-and-subtitles/) | [Audio & Video Transcription](https://apify.com/wrentools/audio-video-transcription) |
| [Turn PDFs into Markdown and RAG-ready chunks](pdf-to-markdown-and-rag-chunks/) | [PDF to Text & Markdown Extractor](https://apify.com/wrentools/pdf-text-markdown-extractor) |
| [Read the text in scanned PDFs and images with OCR](ocr-scanned-pdfs-and-images/) | [Image & Scanned PDF OCR](https://apify.com/wrentools/scanned-pdf-image-ocr) |
| [Pull the text out of a folder of screenshots into one searchable CSV](text-from-a-folder-of-screenshots/) | [Image & Scanned PDF OCR](https://apify.com/wrentools/scanned-pdf-image-ocr) |
| [Turn podcast episodes into searchable transcripts](podcast-episodes-to-searchable-transcripts/) | [RSS Feed Reader](https://apify.com/wrentools/rss-feed-reader) and [Audio & Video Transcription](https://apify.com/wrentools/audio-video-transcription) |
| [Download every file from a list of links into one folder, with checksums](download-files-from-a-list-of-links/) | [Bulk File Downloader](https://apify.com/wrentools/bulk-file-downloader) |
| [Turn RSS, Atom and JSON feeds into one spreadsheet of posts](rss-feeds-to-a-spreadsheet/) | [RSS Feed Reader](https://apify.com/wrentools/rss-feed-reader) |
| [Merge lead lists from CSV, JSON and Excel files and remove duplicates](merge-and-dedup-lead-lists/) | [Merge & Dedup Datasets](https://apify.com/wrentools/dataset-merge-dedup) |
| [Check a sitemap for broken links](check-a-sitemap-for-broken-links/) | [Sitemap Validator](https://apify.com/wrentools/sitemap-validator) |
| [Run an SEO check on your own site](seo-check-your-own-site/) | [Own-Site SEO Audit](https://apify.com/wrentools/own-site-seo-audit) |

**Disclosure:** we built and sell the Actors these examples call. The examples are written with AI assistance, and
each one is run against the live Actor before it is published here.

Also by WrenTools: [Offline OCR: Copy Text from Screen](offline-ocr/), a Chrome extension that copies the text
from any part of the screen, read on your own computer. Get it on the
[Chrome Web Store](https://chromewebstore.google.com/detail/mfaolaapfbdmfilfgjgcpkdgfimljdpj).

Issues and questions about an example are welcome in this repository's Issues.
